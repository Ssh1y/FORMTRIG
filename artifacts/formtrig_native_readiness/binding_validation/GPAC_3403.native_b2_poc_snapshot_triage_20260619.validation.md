## Interpretation

The previous B2 60s campaign remains useful partial evidence: it produced
non-trigger lifted progress and a non-constant spec-driven `D_F`. This PoC
snapshot triage narrows the blocker: the missing `same_object` role is not just
a short-run sampling issue. The current alias role is bound to
`gf_bs_new_cbk_buffer`, but the actual GPAC_3403 raw-HEVC PoC path reaches
root/lifecycle/producer signal without reaching that function.

Next action: repair the object-alias role around the actually reached
cleanup/free path, or reseed toward a path that reaches `gf_bs_new_cbk_buffer`,
before promoting GPAC_3403 as complete same-object lifecycle evidence.

Raw local evidence is under `/tmp/gpac3403_snapshot_*` and
`/tmp/gpac3403_gfbsnew_probe_*`. The committed JSON summary records hashes,
